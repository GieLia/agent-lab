# Profiles

Provider-neutral reusable agent role contracts.

Profiles define:

- purpose;
- responsibilities;
- inputs;
- outputs;
- allowed skills;
- allowed tools;
- prohibited actions;
- required policies;
- completion criteria.

Current profiles:

- research-lead
- researcher
- critic
- evidence-verifier
- synthesizer

Profiles do not select a provider, model, account,
Linux user, or concrete runtime implementation.

Those concerns are bound separately by the runtime.
