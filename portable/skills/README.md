# Skills

Provider-neutral reusable methodologies.

A skill describes HOW a task should be performed.

Current skills:

- acceptance-gating
- critique

- web-research
- source-verification
- synthesis
- knowledge-update

Skills define:

- purpose;
- inputs;
- outputs;
- procedure;
- retry conditions;
- stop conditions;
- prohibited behavior;
- required policies.

Skills do not select models, providers, accounts,
OS identities, or concrete tool implementations.
